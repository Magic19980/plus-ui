# 动森模式主题规范

动森模式是科室管理平台的第二套工作模式。它只改变视觉组件和应用壳，不改变路由、接口、权限、表单值或业务状态。

> `animal-island-vue` 当前发布说明标注为学习和非商业使用。上线前请确认项目授权范围；如果系统属于商业交付，应将适配器保留为接口层并替换为自有组件样式。

## 使用规则

- 新页面优先从 `@/components/UiKit` 引入 `UiButton`、`UiCard`、`UiInput`、`UiSelect`、`UiDatePicker`、`UiTimePicker`、`UiNumberInput`、`UiRadioGroup`、`UiCheckbox`、`UiCheckboxGroup`、`UiTextarea`、`UiTag`、`UiTabs`、`UiDialog`、`UiDrawer`、`UiEmpty`、`UiTable`、`UiTooltip`、`UiUpload` 等组件。
- 业务页面不应直接依赖 `animal-island-vue`，主题判断和组件切换集中在 UiKit。
- 状态颜色使用 `--animal-status-success/warning/danger/info`，不要在页面中新增固定色值。
- 交互组件必须保留 `v-model`、`change`、`loading`、`disabled`、键盘操作和无障碍标签。
- 仅在 Animal 组件没有对应能力时回退到 Element Plus，并在组件适配器中记录原因。

当前文件上传使用 `UiUpload` 统一承载 Element Plus 的上传行为；Animal Island 尚无对等上传组件，
因此适配器会保留上传、进度、删除和预览事件，并通过动森主题类名统一视觉。后续替换底层实现时，
业务页面无需调整。

表格使用 `UiTable` 作为复杂能力适配层，支持选择列、序号列、展开行、客户端/远程分页、客户端排序、
自定义排序事件、列筛选、固定列、横向/纵向滚动、行高亮、空状态、加载状态以及单元格/表头插槽。
历史页面仍可使用 `DepartmentDataTable` + `el-table-column` 写法：办公模式原样使用 Element Plus，
动森模式自动转换列配置和插槽。带 `tree-props`、`default-expand-all` 或懒加载的树形表格也由
`UiTable` 负责保留层级、展开状态和行操作；动森模式默认使用视口内表体滚动，业务传入的
`max-height` 会覆盖默认值，让表头固定并在表体内滚动；页面自身的纵向滚动则作为内容超出视口时的兜底。

## 视觉令牌

页面只使用语义变量：

| 用途 | 变量 |
| --- | --- |
| 主操作 | `--animal-primary-color` |
| 成功、警告、危险、信息 | `--animal-status-*` |
| 页面、卡片、控件背景 | `--app-shell-bg`、`--app-surface-bg`、`--animal-bg-color-input` |
| 标题和辅助文字 | `--animal-text-color`、`--animal-text-color-secondary` |
| 边框和焦点 | `--animal-border-color`、`--animal-focus-ring` |

## 适配器契约

适配器必须同时验证办公和动森两种模式：

1. 属性不会静默丢失；无法映射的属性要有明确回退。
2. 事件参数和 `v-model` 值格式保持一致。
3. 图标使用插槽或组件渲染，不把组件对象转换成字符串。
4. 弹层必须支持 ESC、点击遮罩关闭和焦点回收。
5. 下拉、日期、表格在 375px、768px、1440px 下都可用。

## 视觉回归清单

- 登录页、首页、导航栏、设置抽屉
- 表格、分页、表单、日期范围、上传、空状态
- 浅色/深色、加载/禁用/错误/成功状态
- 主题刷新后保持不闪烁，业务数据和权限不变化
